# Security and privacy

TestClub is a static website: there are no accounts, no server and no stored user data, and progress
never leaves the visitor's browser. The main risk is material that should not be public, so privacy
reports are handled first.

## Reporting a problem

Report any of these:

- personal data in the notes, questions or slide snapshots: a name, an e-mail address, a login, a
  student number or an internal hostname;
- a slide snapshot that shows more of a lecture than a short excerpt;
- a security problem in the site itself, such as a way to run script through the content.

Open an issue with the [**Privacy problem**](https://github.com/abhuiyan00/TestClub/issues/new?template=privacy.yml)
form. Say where the problem is (course, lecture, slide or page), but **do not copy the personal data
into the issue**. The affected item is taken offline first and corrected afterwards.

## Supported versions

Only the live site and the `main` branch are maintained.
