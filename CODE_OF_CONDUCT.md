# Code of conduct

TestClub is made by students for students. Everyone who takes part, in issues, pull requests or
discussions, is expected to:

- be respectful and patient, especially with people who are new to Git or to a course;
- criticise ideas and content, never people;
- keep other people's personal data private, including classmates and teachers;
- keep exam integrity: no leaked test papers, no answers to tests that are still running.

Harassment, insults and discriminatory language are not tolerated. Maintainers may edit or remove
comments, close issues and block accounts that break these rules.

To report a problem privately, contact a maintainer through their GitHub profile.
